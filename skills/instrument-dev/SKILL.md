# 仪器研发工具箱（Instrument Dev Toolkit）

面向地震仪（宽频带/短周期/加速度计）与地磁仪（磁通门/质子旋进/光泵）及配套采集系统的研发与测试协议。**测试可复现性 = 记录环境条件 + 设备身份 + 固件/软件版本 + 完整原始数据**。

## 标定（Calibration）

### 灵敏度标定
- 地震计：电流注入法（calibration coil）、阶跃响应、正弦扫频；记录标定电流值、线圈常数、输出电压。
- 磁通门磁力仪：标准磁场线圈（Helmholtz 线圈）标定，记录线圈常数（nT/A）、电流精度；与质子旋进磁力仪（总强度绝对测量）对比标定。
- 质子/光泵磁力仪：质子旋进频率 → 磁场（γ_p = 42.576 MHz/T），用绝对场比对（地磁台绝对观测）。

### 频率响应测量
- 方法：正弦扫频（逐频点）、阶跃响应（时域→传递函数）、宽频带噪声激励+互谱（已知参考传感器/信号源）；
- 拟合：传递函数 → 极零点（poles/zeros）+ 归一化因子；二阶系统参数（固有频率 f0、阻尼比 ζ）；
- 相位响应与群延迟：记录滤波/传感器相位，避免与信号处理相位混淆；
- 输出：标定报告（拟合参数、残差、频率范围、温度条件）。

### 线性度与动态范围
- 谐波失真 THD（多频点）、压缩点、饱和阈值（满量程）；
- 动态范围 = 满量程 / 本底噪声（dB）；本底噪声以噪声密度谱表示（加速度：m/s²/√Hz；磁场：nT/√Hz 或 pT/√Hz）；
- **自噪声 vs 环境噪声**：双仪器同址（同型号两台，互谱法/相干法分离自噪声与环境噪声）、或放在已知低噪声环境（深井/磁静环境）测量。

## 环境与可靠性测试

- 温漂测试：温度循环（记录温度箱曲线），输出灵敏度/相位/基线的温度系数（%/°C、nT/°C）；每台设备序列号单独建档；
- 湿度/气压/老化：长时稳定性（漂移率）、上电重复性；
- 测试矩阵：参数 × 条件 × 重复次数，每格记录原始数据文件路径与时间戳；
- 测试环境条件（温度、湿度、供电电压、接地情况）必须逐次记录。

## 数据采集系统（DAQ）

- ADC 参数：位数、采样率、动态范围（SFDR/SINAD/ENOB）、增益档与满量程电压、量化噪声水平；
- 抗混叠滤波：截止频率与滚降、滤波器类型（巴特沃斯/椭圆）、与采样率的关系（采样率 ≥ 2× 信号带宽，留裕量）；
- 时钟：GPS 授时/OCXO/TCXO；测试长时间时钟漂移（ppb/天），记录时间标签误差分布；
- 数据完整性：丢数检测（连续记录 gap 统计）、记录文件切分与索引、MiniSEED 或自定义格式的块头完整性；
- 电源：供电电压纹波、断电恢复行为、功耗（野外电池/太阳能预算依据）。

## 时间同步协议

- 同步方式：GPS（绝对）、PTP（局域高精度）、NTP（一般）；记录锁星情况、PPS 信号；
- 漂移测试：与参考时钟对比（多日），量化频率偏差；部署后定期回访检查时间误差（与 GPS 对时前后对比）；
- 时间标签误差直接影响走时/定位/互相关——**时间精度要求（如 <1 ms）在设计阶段明确**。

## 野外部署协议

1. 选址：地震台——背景噪声测试（便携设备试测）、避开人为干扰源（道路/河流/风噪）、地动条件；地磁台——磁场梯度测量（选低梯度点）、避开铁磁性物体（管线/建筑/铁轨/供电线路）、磁静条件评估；
2. 安装：地震计——定向（N 向标识）、水平调节、埋深与耦合、防风/隔热；磁通门——定向（磁北）、水平、远离磁性部件（标定后方位角记录）、电缆磁清洁；
3. 现场测试：安装后观测一段时间确认数据质量（波形形态、噪声水平、日变化形态）、时间同步验证；
4. 记录：部署报告（坐标/高程/定向角/埋深/设备序列号/固件版本/标定日期/照片），写入 data/ 台站清单；
5. 回访与数据回收：定期下载、质量检查、时间校正记录；仪器变更必须标注（影响地磁基线）。

## 仪器对比与验证

- 同址并行观测：新仪器与参考仪器（已标定）同台站对比，评估一致性（相关系数、偏差、标准差）；
- 地震：波形一致性、谱一致性；地磁：分量差（ΔX/ΔY/ΔZ）均值与标准差、基线差；
- 不确定度估计：标定不确定度传播（灵敏度、响应、时间、温度）；
- 出厂/验收测试清单：逐项打勾并留档。

## 固件与版本管理

- 固件/软件版本、配置参数、标定日期、序列号——统一记录在设备清单（`data/devices.tsv` 或台站清单扩展列）；
- 固件升级前后各做一次标定/性能测试，记录差异；
- 配置文件版本化归档（与代码同库），恢复现场可复现；
- 每台设备单独目录：标定报告、测试数据、固件版本、维护记录。

## 常见坑

- 温漂未记录 → 灵敏度随温度变化无法解释；
- 地震计定向错误/地磁仪方位角错误 → 分量数据作废；
- 地磁仪器附近铁磁性物体/直流供电干扰；
- 接地环路、电缆运动（Triboelectric）、电磁干扰（50 Hz 工频）；
- 时钟漂移未检测 → 走时/互相关结果偏差；
- 采样率与响应带宽不匹配（欠采样/无抗混叠）；
- 量程溢出（削波）未检测；
- 标定报告缺环境条件 → 无法复现。

## 复现纪律

所有测试：环境条件、设备身份、固件版本、参数、原始数据文件路径逐一记录；结果（标定报告、测试矩阵、部署报告）用 artifact_save 归档，方法节按 provenance 复现。
