# dsh-science-geophysics

**A geophysics research workbench for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)** — built for seismology / geomagnetism / geophysical-instrument projects. Forked from [dsh-science](https://github.com/biociao/dsh-science): the domain-agnostic engines are kept in sync with upstream (zero third-party deps), while the persona, skills and scaffolds are localized to geophysics.

- **ReAct research-loop engine** — `research_init/state/hypothesis/experiment/findings/phase/review/report`, state persisted in `research-manifest.json` (Question → Hypothesis → Experiment → Observe → Analyze → Conclude → Next question).
- **Versioned artifacts with provenance** — `artifact_save/list/show/diff/verify/deprecate/reproduce`: results stored as `artifacts/<name>/v<N>/` with per-file SHA-256, `artifact.json` provenance (command/inputs/environment/envFile) and append-only `provenance.md`.
- **12 research skills** — research-loop, science-project-setup, artifact-provenance, scientific-reviewer, literature-connector, parallel-delegation, manuscript-writing, **seismology-toolkit**, **geomagnetism-toolkit**, **instrument-dev**, conda-environments, data-inventory.

**Verified against DSH 0.2.1-rc.2** — `peerDependencies: {"@deepseek-ai/dsh": ">=0.2.1-rc.2"}`. Both installers (`scripts/install.sh`, `scripts/install.ps1`) probe the installed `dsh` version first and warn — asking for confirmation only on an interactive terminal, never blocking a non-interactive run — when it is older than that floor.

- **Reproducible environment + declared skill dependencies** — `envs/environment.yml` (conda-forge: obspy, pygmt, ppigrf, …) is written idempotently by `scripts/init-project.sh`; every `skills/*/SKILL.md` carries a `requires:` frontmatter block (keys limited to python / conda / pip / cli / tools / services; `tools` only names `tool-*` rows that really exist in `preset/agent.cordis.yml`).
- **One validation entry point** — `npm run check` = `node scripts/smoke-test.mjs` + `bash test/verify-bundle.sh` (five classes): reference-name resolution against the installed DSH (`@deepseek-ai/dsh-*` in package.json / cordis.patch.yml / preset / scripts), skill frontmatter + `requires` validation, an `envs/environment.yml` YAML check, the smoke test, and a `cordis.patch.yml` preset-declaration check (parseable YAML, `config.id`/`config.plugins` present and aligned with `preset/agent.cordis.yml`, every `@deepseek-ai/*` and `dsh-science-geophysics/*` reference resolving to a real target).

Install once as a bundle — `bash scripts/install.sh` (npm pack → `dsh plugin --profile web add <tgz>`). Since dsh 0.2.1-rc.2 a preset is a bundle-patch declaration row rather than `$DSH_HOME/.agent-presets/<id>/`, so this one patch carries both the profile-level engine rows and the **地球物理模式** agent preset (persona + engines, agent-scoped). Confirm with `dsh plugin --profile web list` and `dsh --profile web --dump-config`. See README.zh.md for full documentation (Chinese).
